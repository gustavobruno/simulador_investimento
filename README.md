# 📈 Simulador de Investimento com Juros Compostos

Este projeto é um simulador financeiro que calcula o crescimento de um investimento ao longo do tempo, considerando:

- **Investimento inicial** (valor único no início)
- **Aportes mensais** fixos
- **Taxa de juros anual** (composta mensalmente)
- **Período de investimento** (em anos)

## 🧮 Como funciona

O simulador aplica a fórmula de juros compostos com aportes periódicos, gerando:

- Evolução anual do capital acumulado (gráfico de linha)
- Montante final total
- Detalhamento entre:
  - Total investido (aportes)
  - Total em juros acumulados

### Exemplo de saída

> Com **€5.000,00** iniciais, **€6.680,00/mês**, **19,00% a.a.** durante **22 anos**, o montante final é de **€20.781.192,99** – sendo **€1.768.520,00** em aportes e **€19.012.672,99** em juros.
