# simulador_investimento
O simulador permite ao usuário ajustar parâmetros como investimento inicial, aporte mensal, taxa de juros anual e período de investimento, exibindo gráficos de crescimento do capital acumulado e detalhando a composição entre montante investido e juros gerados.

The simulator allows the user to adjust parameters such as initial investment, monthly contribution, annual interest rate, and investment period, displaying growth charts of the accumulated capital and detailing the composition between the total amount invested and the interest generated.
